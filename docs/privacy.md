# プライバシーポリシー

本ポリシーは、斎藤商店アプリ班（以下、「開発者」といいます）が提供するアプリ『拼読（ピンドク）』（以下、「本アプリ」といいます）における、ユーザーの個人情報の保護について定めるものです。

### 1. 個人情報の収集と利用について
本アプリ自体が、ユーザーの名前、住所、電話番号、クレジットカード情報などの個人情報を収集することはありません。

### 2. お問い合わせ時の情報の扱い
ユーザーからメールでお問い合わせをいただいた際、返信先のメールアドレスやお問い合わせ内容が開発者に送信されます。
* **利用目的**: お問い合わせへの回答および本人確認のため。
* **第三者提供**: 法令に基づく場合を除き、取得したメールアドレスを第三者に提供することはありません。

### 3. アプリ内課金について
本アプリの有料コンテンツは、すべてApple Inc.またはGoogle Inc.の提供する決済システムを利用しています。
開発者がユーザーのクレジットカード番号や銀行口座情報を取得・保持することはありません。

### 4. 解析・広告ツールの利用
本アプリの利用状況把握のため、以下のツールを使用することがあります。
* **Firebase (Google Inc.)**: 利用状況の統計を取るために使用します。個人を特定する情報は含まれません。

### 5. 免責事項
本アプリの利用によって生じたトラブルや損失・損害に対して、開発者は一切の責任を負いません。

### 6. お問い合わせ先
本ポリシーに関するお問い合わせは、サポートページ内のお問い合わせフォームまでお願いいたします。
